# Авторизація та безпека

Реалізуйте безпечну реєстрацію та вхід: password hashing, JWT у HTTP-only cookies, refresh tokens і ролі. Додайте CORS, rate limiting, валідацію та змінні середовища. Результат етапу - застосунок з авторизацією й ролями користувачів.
