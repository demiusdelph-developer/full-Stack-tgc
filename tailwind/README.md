# Tailwind CSS

Tailwind CSS - utility-first CSS-фреймворк. Замість написання великої кількості власних класів ви збираєте інтерфейс із готових utility-класів, але все одно застосовуєте знання звичайного CSS.

## Передумови

Перед Tailwind вивчіть семантичний HTML, CSS, Flexbox, Grid, responsive design і accessibility. Тоді класи Tailwind будуть зрозумілими, а не набором символів для копіювання.

## Вивчити

- встановлення Tailwind через npm у Vite-проєкті;
- spacing, typography, colors і states;
- Flexbox, Grid та responsive prefixes;
- hover, focus і dark mode;
- налаштування теми й повторне використання компонентів;
- доступні форми, кнопки та навігацію.

## Практика

Зберіть адаптивну сторінку профілю або невеликий каталог. Використайте mobile-first підхід, keyboard focus styles, темну тему та повторно застосовувані UI-компоненти.

## Результат

Адаптивний інтерфейс, зібраний Tailwind CSS без втрати семантики та доступності.
