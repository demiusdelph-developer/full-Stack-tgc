# Sass

Sass - це препроцесор CSS, який додає змінні, вкладені правила, mixins і модульну структуру. Браузер не читає Sass напряму: `.scss`-файли компілюються у звичайний CSS.

## Передумови

Спочатку впевнено використовуйте чистий CSS: selectors, cascade, box model, Flexbox, Grid і адаптивність. Sass прискорює роботу, але не замінює розуміння CSS.

## Вивчити

- синтаксис SCSS і компіляцію через npm;
- змінні для кольорів, відступів і breakpoints;
- вкладені правила без надмірної глибини;
- partials, `@use` і модульну організацію стилів;
- mixins для повторюваних стилів;
- математичні операції та функції.

## Практика

Перенесіть стилі адаптивного лендінгу з CSS у SCSS. Розділіть їх на файли `base`, `components`, `layout` і `utilities`, створіть змінні для дизайн-токенів і один mixin для media queries.

## Результат

Проєкт із зрозумілою структурою SCSS, який компілюється в один CSS-файл.
